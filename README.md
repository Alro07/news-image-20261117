Draws a one-page infographic summing up Tuesday 17 November 2026's world news — six verified stories across Europe, the Middle East, Asia-Pacific and Africa, plus a ticker of two more — as a 1024×1024 PNG. The image is generated by `tools/gen_image.py` and committed as `entry.png`; `main.py` (Python 3.13, standard library only) copies it to `/output/entry.png`, deterministically and with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To redraw the image from scratch (needs Pillow and DejaVu fonts):

```sh
python3 tools/gen_image.py
```
